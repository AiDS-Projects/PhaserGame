# 视觉规范 — 实现二段跳与受控状态管理

> 所属需求：平台跳跃可玩原型：主角二段跳 + 冲刺

## 整体风格
整体采用扁平化科幻风，深色背景（#0F172A）承载高对比霓虹点缀，突出玩家与可交互状态。角色在原型阶段以圆角矩形占位，用绿色（primary）标识角色、蓝色（secondary）标识二段跳可用、紫色标识冲刺占位，形成清晰的色彩语义系统。HUD 保持低信息密度，仅跳跃次数与冲刺占位两个指标，避免干扰核心平台跳跃玩法。

## 组件视觉规范

# 组件视觉规格

## 1. 主角角色（占位矩形）
- **地面形态**：32x40 圆角矩形，填充 `#4ADE80`（primary），描边 `#16A34A` 2px，圆角 `radius.md`。
- **二段跳激活形态**：跳起后首次离地即切换为 `#38BDF8` 描边，外发光 `shadow.glow_ready`，提示玩家仍有一次空中跳可用。
- **跳跃次数耗尽形态**：主体填充 `#4ADE80` 保持可辨识，描边降为 `#475569`，无外发光。
- 面向：原型阶段为单色方块，不区分朝向，后续替换为 sprite 帧。

## 2. 地面与平台
- **地面**：全宽矩形，填充 `#64748B`，顶部 2px 高亮线 `#94A3B8`。
- **平台（单向下落平台）**：填充 `#334155`，描边 `#475569` 1px，顶部 2px 高亮线 `#64748B`，圆角 `radius.sm`。
- 与 Arcade Physics 碰撞体对齐，视觉块即为碰撞体，避免视觉与物理错位。

## 3. HUD — 跳跃次数指示器
- **位置**：屏幕左上角，间距 `spacing.md`。
- **结构**：标题文本 `JUMP`（`text_muted`、`typography.sm`）+ 两枚圆点指示器。
- **圆点状态**：可用 = `#38BDF8` 实心圆（12px）+ `shadow.glow_ready`；已用 = `#475569` 空心圆（描边 1.5px）。
- **背景**：`bg_panel` 半透明（alpha 0.7），圆角 `radius.md`，内边距 `spacing.sm`。

## 4. HUD — 冲刺占位（Dash）
- **位置**：跳跃指示器下方，间距 `spacing.sm`。
- **结构**：标签 `DASH` + 胶囊形占位图标（24x12，填充 `dash_locked`，圆角 `radius.pill`）。
- **状态**：本工单固定为锁定态（`dash_locked` + 挂锁小图标 16px outline），交互 hover 无变化，仅作接入点占位。

## 5. 落地反馈（Grounded）
- 落地瞬间跳跃指示器圆点恢复满格，可选播放一次 150ms 的圆点 `glow_ready` 脉冲（原型可选）。
- 不额外渲染 Toast，避免信息噪声。

## 6. 调试叠加层（可选，开发期）
- 显示 `touching.down` 状态与跳跃次数，使用 `typography.sm`、`text_muted`，位于屏幕右上角，`spacing.md` 边距。
