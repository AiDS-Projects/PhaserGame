# PRD — 实现玩家移动与重力物理

> 所属需求：平台跳跃可玩原型：主角二段跳 + 冲刺

## 用户故事
As a 玩家，I want to 使用键盘（← → / A D）控制主角左右移动、受重力影响自然下落并与地面/平台发生碰撞，同时相机自动跟随主角移动，So that 我能体验横版平台跳跃的基础手感并为二段跳/冲刺等后续玩法奠定基础。

## 功能需求
功能点 1：主角为矩形精灵，初始位置固定在场景地面正上方，接入 Arcade Physics 重力，Y 轴重力加速度默认 Phaser 全局配置（约 300），角色落地后受平台碰撞体支撑不下落、不穿墙。\n功能点 2：左右移动——按住 ← / A 向左、按住 → / D 向右，水平速度可配置（建议 160~200 px/s），松开按键后水平速度立即归零，移动方向与朝向（flipX）保持一致。\n功能点 3：边界限制——主角水平移动被场景左右边界（world bounds 或摄像头 bounds）约束，不可越出，碰撞体 body 与边界不发生重叠穿出。\n功能点 4：平台碰撞——场景包含 1 块地面与 ≥3 块静态平台，平台使用 immovable 静态碰撞体，主角从上方落下可站立、从下方/侧面碰撞不穿透。\n功能点 5：相机跟随——主相机跟随主角（startFollow），仅在水平方向跟随，设置跟随偏移使主角位于画面左 1/3 处，跟随带可选 lerp 平滑。\n功能点 6：状态通过受控 action 更新——移动速度、是否落地（onGround）、朝向等不直接改属性，统一由动作方法或服务层修改。

## 验收标准
- [ ] 页面加载后 2s 内主角出现在场景中并受重力下落至地面，落地后静止不抖动、不穿透地面\n- [ ] 按住 → 或 D 键，主角在 100ms 内开始向右移动，水平速度稳定在 160~200 px/s 区间（误差 ±10%）\n- [ ] 松开移动键后 100ms 内主角水平速度归零并停止\n- [ ] 主角水平移动至场景左右边界时，角色碰撞体与边界重叠深度 ≤ 1px，不越界、不卡死\n- [ ] 主角从平台正上方落下后可站立于平台上，下落过程无穿墙；从平台下方跳跃碰撞时被阻挡不下落穿透\n- [ ] 相机水平跟随主角，主角始终保持在画面水平方向左 1/3 位置（误差 ±10% 屏宽）；垂直方向相机保持初始 Y 不变\n- [ ] 主角朝左移动时精灵水平翻转（flipX=true），朝右移动时恢复（flipX=false），切换在 1 帧内生效\n- [ ] 主角站立于地面/平台上时，持续按住移动键，角色保持贴地不悬空、不陷入平台\n- [ ] 60fps 目标下，移动与碰撞过程中帧率 ≥ 55fps，无持续掉帧

## 边界条件（不做的事）
不包含：跳跃、二段跳、冲刺、无敌帧与冷却等能力（属于后续工单）。\n不包含：敌人、关卡切换、积分/生命系统、音效与背景音乐、美术资源（使用纯色矩形/简单精灵占位）。\n暂不支持：移动端虚拟摇杆/触控按钮（原型阶段优先桌面键盘，后续工单再做）。\n不包含：斜向移动、跑步/疾跑速度分级、爬墙/斜坡物理、移动平台或动态物理体。\n超出范围：多角色、联网同步、存档与设置面板。

## 资产需求线索
暂无（使用 Phaser 内置 Rectangle 图形或纯色矩形精灵占位，无需外部图片/音效/动画资产）。
