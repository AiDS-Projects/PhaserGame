# PRD — 实现冲刺、无敌帧与冷却反馈

> 所属需求：平台跳跃可玩原型：主角二段跳 + 冲刺

## 用户故事
As a 玩家，I want 按下 Shift 让主角朝面向方向快速冲刺并获得短暂无敌与冷却反馈，So that 我能用冲刺规避危险、拉近与平台的相对位置，同时通过 UI 清楚知道何时能再次冲刺。

## 功能需求
1. 冲刺触发：桌面键盘按下 Shift 键触发冲刺；冲刺方向取主角当前朝向（最后水平移动方向），若从未水平移动则默认朝右。
2. 冲刺运动：冲刺期间水平速度固定为朝向方向 × 800 px/s，持续 150ms 后自动结束；冲刺期间垂直速度不受影响，仍遵循原有重力逻辑。
3. 无敌帧：冲刺开始后的 150ms 内主角处于无敌状态（isInvincible = true），150ms 后立即恢复（isInvincible = false）。
4. 冷却：单次冲刺冷却时间 1500ms；冷却期间再次按下 Shift 不触发冲刺（速度不变、不重置冷却）。
5. UI 冷却反馈：HUD 显示冲刺冷却状态——冲刺可用与不可用两种视觉状态明确区分；冷却期间以进度条显示剩余冷却时间，冷却结束恢复可用状态。
6. 状态管理：冲刺相关状态（isDashing、isInvincible、dashCooldownRemaining）全部通过受控 action 更新，禁止直接赋值 store/内部属性。
7. 代码规范：遵循 TypeScript 规范——禁止 any、公共逻辑沉淀至 utils/services、变量与函数名使用英文。

## 验收标准
- [ ] 主角在任意状态（地面/空中）下按下 Shift，50ms 内沿朝向方向开始冲刺，冲刺水平速度 ≥ 800 px/s。
- [ ] 单次冲刺水平位移在 120~180 px 范围内，冲刺持续 150ms 后自动停止。
- [ ] 冲刺开始后 0~150ms 期间 isInvincible === true，150ms 后 isInvincible === false。
- [ ] 冲刺冷却时间为 1500ms；冷却期间再次按 Shift，主角水平速度与冲刺状态无任何变化。
- [ ] 冷却期间 UI 进度条从 0% 到 100% 在 1500ms 内匀速增长，误差 ≤ 50ms。
- [ ] 冷却结束（1500ms）后 100ms 内 UI 由「不可用」切换为「可用」状态，两种状态视觉可区分（颜色/透明度/图标至少一项不同）。
- [ ] 若主角从未水平移动，冲刺默认朝右；若最后移动方向为左，冲刺朝左。
- [ ] 冲刺相关状态仅通过受控 action 变更，代码审查中无对 store/内部属性的直接赋值，且无 any 类型。
- [ ] 冲刺动作期间游戏循环帧率 ≥ 55fps，无可见卡顿。

## 边界条件（不做的事）
不包含：敌人与伤害/掉血系统（无敌帧仅预留，本工单不实现受伤判定与生命值）。
不包含：移动端虚拟摇杆/虚拟按钮。
不包含：音效、美术资源、冲刺残影/拖尾粒子特效。
不包含：冲刺升级、多段冲刺、空中冲刺次数增加、冲刺距离成长等扩展。
不改变：既有左右移动与二段跳的数值与手感。

## 资产需求线索
图标：冲刺技能图标（UI 占位，可用纯色矩形/色块代替）。
图片：冷却进度条背景与填充（占位，可用纯色矩形）。
音效：冲刺音效（暂无）。
特效：冲刺残影/拖尾（暂无）。
动画：冲刺姿态动画（暂无）。
