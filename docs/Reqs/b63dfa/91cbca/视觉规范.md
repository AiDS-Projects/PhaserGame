# 视觉规范 — 可玩原型验收自测

> 所属需求：平台跳跃可玩原型：主角二段跳 + 冲刺

## 整体风格
整体采用深色扁平风格，避免复杂纹理，突出测试期 HUD 状态可读性与输入反馈。使用高饱和点缀色区分跳跃（绿）、冲刺（紫）、无敌（黄）三类关键状态，配合等宽字体保证数值对齐、可快速判读。原型阶段以矩形占位精灵呈现，视觉重心放在 HUD 与触控控件上，确保验收截图信息清晰可回溯。

## 组件视觉规范

# 组件视觉规格 — 可玩原型验收自测

## 1. HUD 状态只读面板（左上角）
- 容器：半透明深色玻璃面板 `surface_glass`(#1E293BE6)，圆角 `radius.md`(8px)，内边距 `spacing.md`(16px)，阴影 `shadow.md`。
- 边框：1px `border`(#334155)。
- 标题 "STATE"：`heading` 20px、`weight_bold`、色 `text`(#F8FAFC)，下方 1px 分隔线 `border`。
- 状态行：`mono` 12px 等宽字体，label 色 `text_muted`(#94A3B8)，value 色 `text`(#F8FAFC)，右对齐。
- 布尔状态 `is_grounded` / `is_invincible`：true 用 `success`(#10B981) 圆点 + 文字，false 用 `danger`(#EF4444)。
- `dash_cooldown_ms`：value 用 `accent`(#F59E0B) 高亮，配合右侧冷却条。

## 2. 冷却指示条
- 位于 HUD 面板底部，宽 100%，高 6px，圆角 `radius.pill`。
- 背景轨道：`bg_secondary`(#1E293B)；填充：`accent`(#F59E0B)，宽度随 cooldown 剩余比例线性收缩，从右向左递减。
- 冷却就绪时填充 `success`(#10B981)。

## 3. 虚拟摇杆（触控模式，左下角）
- 外圈：直径 120px，2px 描边 `border`，`surface_glass` 半透明填充，圆角 50%。
- 摇杆头：直径 48px，`primary`(#4F46E5) 填充，阴影 `shadow.md`，随触摸位移。
- 命中区域须 ≥ 44px，保证可交互。

## 4. 动作按钮（触控模式，右下角）
- 跳跃按钮：直径 64px 圆形，`success`(#10B981) 填充，激活态加亮 + `shadow.lg`。
- 冲刺按钮：直径 64px 圆形，`primary`(#4F46E5) 填充；冷却中填充 `bg_secondary` + `text_muted` 边框，就绪恢复 `primary`。
- 按钮文字 "JUMP" / "DASH"：`sm` 12px、`weight_bold`、色 `text`(#F8FAFC)。

## 5. 玩家占位（矩形精灵）
- 尺寸 32x40px（宽×高），填充 `player`(#38BDF8)，1px 描边 `text`。
- 无敌帧：填充切换 `player_invincible`(#FDE047)，持续到冲刺结束。
- 可加 4px 白色眼睛矩形指示朝向（可选）。

## 6. 平台 / 地面
- 平台：矩形填充 `platform`(#64748B)，顶面 3px 高亮条 `platform_top`(#94A3B8)，区分可站立顶面。
- 地面：填充 `ground`(#475569)，顶面同平台高亮条。

## 7. 状态颜色速查
| 状态 | 颜色 | 值 |
|------|------|----|
| jump_remaining = 1 | success | #10B981 |
| jump_remaining = 0 | text_muted | #94A3B8 |
| dash 就绪 | success | #10B981 |
| dash 冷却中 | accent | #F59E0B |
| is_invincible true | player_invincible | #FDE047 |
| is_grounded false | danger | #EF4444 |
## 精灵图规格
player_placeholder: 32x40px，1 帧静态矩形，状态通过 tint/填充色切换（默认 player #38BDF8，无敌 player_invincible #FDE047），无需动画帧。
platform_tile: 64x16px 可平铺矩形，1 帧，顶部 3px 高亮条（platform_top #94A3B8）。
ground_tile: 64x64px 可平铺矩形，1 帧，顶部 3px 高亮条。
（原型无行走/跳跃/冲刺逐帧动画，运动表现由物理位移与状态色体现）
