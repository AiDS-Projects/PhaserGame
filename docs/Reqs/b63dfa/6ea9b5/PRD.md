# PRD — 搭建关卡场景：地面与平台

> 所属需求：平台跳跃可玩原型：主角二段跳 + 冲刺

## 用户故事
As a 玩家, I want 一个包含地面、多个平台与世界边界的可玩关卡场景, So that 我能在地面与不同高度的平台之间移动跳跃，且不会穿墙或掉出世界。

## 功能需求
- 关卡场景基于 Arcade Physics，包含 1 段贯穿全关卡宽度的地面（static 物理体）
- 地面之上布置 ≥ 3 个平台，平台为 static 物理体，高度与水平位置错开，形成可跳跃的垂直层次
- 世界边界：关卡宽度大于设计分辨率（960×540），左/右/底部设置边界，角色不能移出世界
- 相机跟随角色，且相机被 world bounds 限制，不超出关卡范围
- 场景背景色使用 COLORS.bg（#0F172A），地面/平台使用现有色彩 token 绘制矩形，不依赖外部美术资源
- 平台与地面的碰撞体尺寸、位置集中在常量/配置中管理，不散落魔法数字
- 重力与角色碰撞相关配置由已存在的 movement 工单负责，本工单仅提供可碰撞的关卡几何体

## 验收标准
- [ ] 打开网页后 3s 内进入 GameScene，背景色为 #0F172A
- [ ] 地面为 static 物理体，宽度 = 1920px（关卡全宽），角色站在地面上 y 坐标持续稳定、不随时间下沉穿透
- [ ] 场景内平台数量 ≥ 3 个，任意两平台之间的水平间距或垂直间距 ≥ 60px
- [ ] 角色从屏幕上方（y≈0）自由下落，落到地面与任一平台时均停止，不发生穿透（tunneling）
- [ ] 角色左右移动时被世界左边界（x=0）与右边界（x=1920）阻挡，无法移出；下落至底部边界时被地面/边界拦住，不坠出画面
- [ ] 相机跟随角色移动，且相机视口始终不超出关卡范围（无黑边越界）
- [ ] 执行 tsc --noEmit 无类型错误，代码无 any，新增配置项沉淀到 config/ 或 constants 共享层

## 边界条件（不做的事）
- 不包含：敌人、关卡系统、音效、美术贴图资源（地面/平台用纯色矩形占位）
- 不包含：角色的移动/二段跳/冲刺逻辑（由对应工单实现，本工单仅提供可碰撞几何体）
- 不包含：平台移动/消失等动态机关，本工单平台均为 static 静态平台
- 不包含：多关卡切换、存档、HUD 积分/生命显示
- 暂不支持：移动端虚拟摇杆/触控按钮（原型阶段优先桌面键盘）

## 资产需求线索
暂无（地面与平台使用 COLORS 色彩 token 绘制纯色矩形占位，不引入外部图片/音效/动画资源）
