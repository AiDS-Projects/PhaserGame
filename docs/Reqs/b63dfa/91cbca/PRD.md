# PRD — 可玩原型验收自测

> 所属需求：平台跳跃可玩原型：主角二段跳 + 冲刺

## 用户故事
As a 验收工程师，I want 用 Playwright 对可玩原型自动截图并模拟键盘/触控输入自测，So that 无需人工逐项操作即可确认移动、二段跳、冲刺、碰撞边界与冷却反馈均满足验收标准。

## 功能需求
功能点 1：提供 Playwright 自测脚本，自动启动 Vite 构建产物（dist/ 或 dev server）并加载游戏页面，页面加载完成（Phaser scene 就绪）后截取初始画面。
功能点 2：脚本模拟键盘输入——按住 →/D 持续移动、按 Space/↑ 起跳与二段跳、按 Shift 冲刺，并在每次输入后截取画面作为视觉证据。
功能点 3：脚本读取游戏暴露的只读状态（如跳跃剩余次数、冲刺冷却剩余时间、角色坐标、是否着地），对输入前后状态做断言，而非仅靠肉眼判断截图。
功能点 4：截图为全页/指定视口 PNG，统一命名（如 01_initial、02_move_right、03_jump、04_double_jump、05_dash、06_cooldown），按时间戳归档到固定目录，便于人工复查手感。
功能点 5：触控兜底——检测到触摸设备（或通过 Playwright 模拟 touch 事件）时，验证虚拟摇杆/跳跃按钮/冲刺按钮的 DOM 元素存在且可交互，并注入触摸事件驱动角色位移。
功能点 6：自测失败时输出结构化失败信息（断言名、期望值、实际值、失败截图路径），供后续修复定位。

## 验收标准
- [ ] 自测脚本从启动到完成首张截图 ≤ 10s，全程脚本退出码为 0（无崩溃/超时）。
- [ ] 按住 →（或 D）持续 500ms 后，角色 x 坐标增量 ≥ 40px；松开后角色水平速度在 200ms 内衰减至 0。
- [ ] 按一次跳跃键后，角色 y 坐标在 300ms 内下降（离地），随后回落到地面且着地状态为 true。
- [ ] 二段跳：空中再次按跳跃键后，跳跃计数由 1 变为 0 且角色再次上升；落地后计数重置为 1。
- [ ] 冲刺：面向右侧按 Shift 后 200ms 内角色 x 位移 ≥ 120px；冲刺期间 invincible 状态为 true，结束后恢复 false。
- [ ] 冲刺冷却：冲刺结束后立即再按 Shift 不触发位移（位移 < 10px），冷却结束后再按可再次位移；冷却剩余时间以可量化数值暴露且单调递减。
- [ ] 碰撞边界：角色与平台/地面碰撞时，任意时刻角色底边不穿透平台顶面（重叠深度 ≤ 2px）；从下方顶平台不会穿墙。
- [ ] 相机跟随：角色 x 偏移超过视口中心 50px 后，相机 x 跟随，角色始终位于视口内；到达关卡左右边界时相机停止（不越界露出背景外区域）。
- [ ] 截图产出 ≥ 6 张 PNG，且初始、移动、跳跃、二段跳、冲刺、冷却六类截图均非纯色空白（画面像素方差 > 0）。
- [ ] TypeScript 静态检查：`tsc --noEmit` 退出码 0、0 处 `any` 类型、0 处 `as` 断言（或每处均有注释说明）。
- [ ] 触控兜底：Playwright 模拟 touchstart/touchmove/touchend 后，角色产生位移（x 增量 ≥ 20px）；虚拟摇杆与按钮元素在触摸视口下可见且可命中。

## 边界条件（不做的事）
不包含：敌人、关卡系统、音效、美术资源（Sprite 用矩形占位即可）。
不包含：真实移动端设备测试，仅通过 Playwright 模拟 touch 事件兜底。
不包含：性能压测（FPS 统计仅作为可选观测，不设硬性通过线）。
不包含：多浏览器矩阵，仅需在 Chromium（Playwright 默认）下通过。
超出范围：录制回放、网络多人在线、存档系统。
