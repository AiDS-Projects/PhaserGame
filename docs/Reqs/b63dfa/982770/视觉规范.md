# 视觉规范 — 初始化 Vite + Phaser 3 + TypeScript 脚手架

> 所属需求：平台跳跃可玩原型：主角二段跳 + 冲刺

## 整体风格
整体采用扁平、低干扰的深色中性占位风格：纯色背景 + 无装饰，强调"空壳可运行"而非视觉表现。色彩以深灰蓝为底、靛蓝为强调色，为后续平台跳跃玩法预留清晰视觉层级。本工单不追求美观，优先保证画布渲染稳定、无白屏、dev 与 preview 表现一致。

## 组件视觉规范

# 组件视觉规格

## 1. 游戏容器 #game-container
- 尺寸：100vw × 100vh，占满视口
- 背景：colors.bg `#0F172A`（canvas 未就绪前的兜底底色，避免白屏）
- 溢出：`overflow: hidden`，无滚动条
- 定位：相对定位，canvas 绝对居中

## 2. Canvas（Phaser.Game 自动创建）
- 挂载点：#game-container
- 缩放策略：Phaser.Scale.FIT（等比缩放 + 居中），禁用拉伸变形
- 背景：由 GameScene 内 `this.cameras.main.setBackgroundColor()` 填充 colors.bg

## 3. GameScene 纯色背景
- 颜色：`#0F172A`（中性深色，作为空壳占位背景，正式玩法工单可替换为天空/场景色）
- 渲染方式：相机背景色填充，非贴图

## 状态颜色（预留，本工单不实现 HUD）

## 精灵图规格
无精灵图需求。本工单仅渲染纯色背景，不包含任何 sprite。预留说明：后续主角精灵规格待玩法工单定义，建议尺寸 32×32，帧动画 idle/run/jump/double_jump/dash。
