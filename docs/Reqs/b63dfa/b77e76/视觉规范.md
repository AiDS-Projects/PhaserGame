# 视觉规范 — 实现玩家移动与重力物理

> 所属需求：平台跳跃可玩原型：主角二段跳 + 冲刺

## 整体风格
采用扁平化极简风格，以深色背景衬托亮色主角矩形，营造清晰可读的平台跳跃原型视觉。所有角色与平台均使用纯色矩形占位，无外部美术资源，通过颜色层级（深底、灰平台、亮蓝主角）建立空间层次。碰撞体线框仅在调试模式显示，保证正式运行画面干净；整体风格为科幻冷色调，强调可玩性与操作反馈优先于视觉细节。

## 组件视觉规范

# 组件视觉规格

## 1. 玩家角色（Player）
- **形状**：纯色矩形精灵（占位，无外部美术）。
- **尺寸**：32x32 px（原型阶段固定，可后续替换为精灵图）。
- **填充色**：`#38BDF8`（player），描边 2px `#0EA5E9`（player_outline）。
- **圆角**：`radius.md` = 4px，视觉柔和。
- **朝向**：向左移动时 `flipX=true`，向右移动时 `flipX=false`，1 帧内切换。
- **阴影**：`0 2px 0 rgba(14,165,233,0.35)`，增强地面贴合感。
- **初始位置**：场景地面正上方约 16px，生成后随重力自然下落。

## 2. 地面（Ground）
- **形状**：横贯场景底部的静态矩形碰撞体。
- **尺寸**：宽度 = 场景宽度，高度约 64px。
- **填充色**：`#64748B`（surface_ground）。
- **顶边高亮**：1px 顶部描边 `#94A3B8`（surface_platform），标识可站立表面。
- **性质**：immovable 静态体，不随碰撞移动。

## 3. 平台（Platform ≥3 块）
- **形状**：静态矩形碰撞体，immovable。
- **尺寸**：宽 120~200px，高 16px，错落分布在场景中（高低不同，间隔可跳达）。
- **填充色**：`#94A3B8`（surface_platform）。
- **顶边高亮**：1px 顶部描边 `#38BDF8`，暗示可站立。
- **布局**：至少 3 块，形成从左到右渐进上升的路径。

## 4. 场景背景
- **背景色**：`#0F172A`（bg），可叠加 `#1E293B`（bg_scene_sky）做垂直渐变。
- **网格参考**（可选 debug）：`#22C55E`（debug_collider）线框，调试期显示碰撞体，发布时隐藏。

## 5. 相机视口
- **跟随**：仅水平跟随（follow X），垂直方向锁定初始 Y。
- **偏移**：主角稳定位于画面左 1/3（约 33.3% 屏宽）。
- **平滑**：`lerp = 0.08` 可选，避免突变抖动。

## 6. HUD（原型阶段可选）
- **内容**：仅 debug 文本（速度、onGround 状态、朝向）。
- **字体**：`ui-monospace`，`sm` = 12px，颜色 `#E2E8F0`。
- **位置**：左上角，间距 `spacing.md` = 16px。

## 状态颜色
| 状态 | 颜色 | 说明 |
|------|------|------|
| 默认/站立 | `#38BDF8` | 角色静止 |
| 移动中 | `#38BDF8` | 颜色不变，仅翻转朝向 |
| 下落中 | `#38BDF8` | 可加轻微缩放感 |
| 边界卡住 | `#FBBF24`（accent） | debug 高亮，提示重叠风险 |
