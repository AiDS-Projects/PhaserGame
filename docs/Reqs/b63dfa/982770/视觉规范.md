# 视觉规范 — 初始化 Vite + Phaser 3 + TypeScript 脚手架

> 所属需求：平台跳跃可玩原型：主角二段跳 + 冲刺

## 整体风格
整体采用暗色科幻像素风底子，为后续横版平台跳跃（二段跳+冲刺）定调：深空底色 `#16161E` 压低视觉噪声，用暖橙 `#FFB454` 与天蓝 `#38BDF8` 两个高饱和强调色分别暗示「跳跃」与「冲刺」两种核心动作，形成稳定的语义色。本工单为脚手架空壳，UI 以简洁扁平为主，信息密度极低，避免过度装饰；所有可交互元素遵循 hover 提亮 + active 缩放的统一反馈节奏，保证后续玩法接入时视觉语言一致。

## 组件视觉规范

# 组件视觉规格

## 1. #app 根容器
- 背景：`#16161E`（与 canvas 背景一致，避免边缘色差）
- 布局：全屏，`position: relative; overflow: hidden; width: 100vw; height: 100vh`
- 无边框、无内边距

## 2. 游戏画布 canvas
- 挂载于容器居中，Scale 模式 `FIT`（保持 16:9 比例留边），缩放阶段背景填充 `#16161E`
- 画布本体无圆角、无阴影，占满可用区域
- 渲染内容：纯色背景 `#16161E` + 占位矩形（`#24283B` 填充、`#3B4261` 描边 2px、圆角 8px）+ 占位文本（`#E5E7EB`，居中）

## 3. Loading 遮罩层
- 背景：`overlay` 半透明遮罩 `rgba(22,22,30,0.72)`，全屏覆盖，`z-index: 10`
- 内容：spinner 图标（24px，outline，`#FFB454`）+ 「加载中」文案（`sm` 12px，`text_dim`）
- 状态：
  - loading：显示，spinner 无限旋转
  - success：200ms `opacity 1→0` fade out 后移除
  - error：切换为错误提示层

## 4. 错误提示层
- 背景：`error_bg` `#3B1D1D`，内边距 `lg` 24px，圆角 `md` 8px，阴影 `md`，居中弹窗
- 文案：错误标题（`lg` 16px，`error` `#F87171`）+ 详情（`base` 14px，`text`）
- 图标：refresh 24px outline，`#F87171`

## 5. 重试按钮
- 默认：背景 `primary` `#FFB454`，文字 `#16161E`（`base` 14px，加粗），内边距 `sm/md`，圆角 `md`，阴影 `sm`
- hover：背景 `primary_hover` `#FFC978`，加 `glow_primary`
- active：`transform: scale(0.95)`
- loading：回到加载态，`opacity 0.6` + `cursor: not-allowed` + `pointer-events: none`（防重复点击）
- disabled：`opacity 0.4`，无 hover 效果

## 6. 预留 HUD 层
- `z-index: 20`，本工单不实现，后续玩法工单承载跳跃/冲刺能量条（用 `secondary` `#38BDF8` 表冲刺，`primary` `#FFB454` 表跳跃）
## 精灵图规格
本工单（脚手架）不产出玩法精灵，以下为后续玩法工单预留规格：
- id: player_idle | size: 32x32 | frames: 4 | loop: true | desc: 主角待机(呼吸/微动), 预留
- id: player_run | size: 32x32 | frames: 6 | loop: true | desc: 主角奔跑循环, 预留
- id: player_jump | size: 32x32 | frames: 2 | loop: false | desc: 起跳/上升帧, 预留
- id: player_double_jump | size: 32x32 | frames: 2 | loop: false | desc: 二段跳(带二次强调色拖尾), 预留
- id: player_dash | size: 32x32 | frames: 3 | loop: false | desc: 冲刺(水平残影), 预留
- id: player_fall | size: 32x32 | frames: 2 | loop: false | desc: 下落帧, 预留
- 占位: 本工单用纯色矩形(32x32, `#E5E7EB`)作为临时占位体，无需精灵图
