# 视觉规范 — 实现冲刺、无敌帧与冷却反馈

> 所属需求：平台跳跃可玩原型：主角二段跳 + 冲刺

## 整体风格
整体采用扁平化 + 明亮青色 (cyan #22D3EE) 作为冲刺技能的专属强调色，与深色半透明 HUD 面板形成高对比，保证信息在快速移动中一眼可读。三种状态（可用/冲刺中/冷却中）通过颜色、透明度、外发光三重视觉通道同时区分，避免仅依赖单一维度导致色弱玩家难以辨认。冷却进度条采用圆角胶囊形、匀速线性增长，符合 PRD 对 1500ms 精确计时的验收要求。

## 组件视觉规范

# HUD 冲刺技能指示器 (Dash Skill Indicator)

## 容器 (Indicator Slot)
- 尺寸：40px × 40px，圆角 `radius.md` (8px)
- 背景色：`hud_bg`（深色半透明，rgba(10,14,22,0.55)）
- 边框：1px 实线 `hud_border`
- 阴影：`shadow.panel`
- 布局：左下角 HUD 区域，与血量/二段跳指示器同一水平线，间距 `spacing.sm` (8px)

## 状态一：可用 (Available)
- 图标：不透明度 100%，填充色 `dash_available` (#22D3EE)
- 图标外发光：`shadow.available_glow`（0 0 8px cyan）
- 边框：1px `dash_available`，透明度 60%
- 附加提示：图标下方 8px 处显示小号标签文字 `dash_primary`，字体 `typography.sm` (12px)

## 状态二：冲刺中 (Active, 150ms)
- 图标：缩放至 115%（scale 1.0 → 1.15），填充色切换为 `dash_primary_bright` (#67E8F9)
- 外发光：`shadow.available_glow_strong`（0 0 14px）
- 无敌帧视觉：角色本体叠加 `invincible_flash` (#FDE047) 半透明闪烁覆盖层 + `invincible_outline` (#FFFFFF) 1px 描边
- 动画时长：与冲刺同步 150ms，缓动 linear

## 状态三：冷却中 (Cooldown, 1350ms)
- 图标：不透明度降至 40%，填充色切换为 `dash_cooldown` (#6B7280)，去除外发光
- 进度条：位于图标底部内侧，高 4px，圆角 `radius.pill`
  - 轨道：`dash_cooldown_track`（rgba(255,255,255,0.14)）
  - 填充：`dash_cooldown_fill` (#22D3EE)，从左向右匀速增长 0% → 100%，总时长 1500ms，ease linear
- 可选：图标中央叠加剩余冷却秒数数字，字体 `typography.sm`，颜色 `text_dim`

## 状态四：冷却结束提示 (Ready Flash, 200ms)
- 冷却完成瞬间：图标闪烁 2 次（不透明度 40% ↔ 100%），随后稳定在「可用」状态
- 闪烁时长 200ms，随后过渡到 Available 样式
## 精灵图规格
- dash_pose_placeholder: 主角冲刺姿态占位精灵图，单帧，48x48px，透明背景；表现为角色前倾、水平拉伸的剪影，填充色可使用角色主色或 cyan #22D3EE 描边。用途：冲刺期间（150ms）临时替换待机帧，向玩家传达加速状态。
- player_idle_placeholder: 主角待机占位精灵图，单帧，48x48px，透明背景；冲刺结束后恢复显示。
- 注：本工单不包含正式美术资产与冲刺残影/拖尾特效，以上均为纯色占位，后续可替换为正式精灵图与多帧动画。
