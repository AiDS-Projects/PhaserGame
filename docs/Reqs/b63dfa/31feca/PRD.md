# PRD — 实现二段跳与受控状态管理

> 所属需求：平台跳跃可玩原型：主角二段跳 + 冲刺

## 用户故事
As a 平台跳跃玩家，I want 在空中再跳一次（二段跳）并在落地后重置跳跃次数，So that 我能到达更高更远的平台，获得流畅的跳跃手感。

## 功能需求
功能点 1：主角可跳跃，跳跃键为 Space 或 ↑，跳跃次数上限为 2 次（地面起跳 1 次 + 空中二段跳 1 次）；跳跃次数通过受控 action（如 playerActions.setJumpCount / playerActions.jump）更新，禁止业务代码直接修改 store/状态属性。
功能点 2：主角处于地面（与地面或平台碰撞）时，跳跃次数重置为上限；仅在离地（非 grounded）状态下允许消耗剩余次数进行二段跳。
功能点 3：跳跃状态判定采用 Arcade Physics 的 grounded（touching.down）信号，而非计时器推断，避免穿墙/无限跳跃。
功能点 4：跳跃力度、重力等参数集中为常量（如 JUMP_VELOCITY、GRAVITY、MAX_JUMP_COUNT），避免魔法数字散落。
功能点 5：冲刺功能（Shift 键）不在本工单实现，但需保留冲刺键位与冷却状态的接入点（受控 action 占位），供下一工单扩展。

## 验收标准
- [ ] 在地面按下跳跃键后，主角竖直速度立即变为负值（向上），起跳响应延迟 ≤ 50ms。
- [ ] 主角离地后（touching.down 为 false）再次按下跳跃键，能成功触发二段跳（跳跃次数从 1 减为 0），且仅能再跳 1 次。
- [ ] 跳跃次数为 0 时，在空中再次按下跳跃键，主角竖直位置不因跳跃产生额外向上位移，即空中最多 2 次跳跃。
- [ ] 主角落地（touching.down 恢复为 true）后，跳跃次数重置为 2，随后可再次完成地面跳 + 二段跳的完整组合。
- [ ] 连续快速按下跳跃键 10 次（间隔 100ms），跳跃总次数 ≤ 2 次/每个空中周期，且主角不出现无限上浮。
- [ ] 跳跃次数变更仅通过受控 action 完成，代码审查中在场景/控制器层找不到对跳跃次数字段的直接赋值（`grep` 直接赋值出现 0 处）。
- [ ] 主角站在平台边缘或平台底部时，不会因二段跳穿墙（穿模），碰撞体始终与地面/平台保持正确接触。
- [ ] 代码通过 TypeScript 编译（`tsc --noEmit` 退出码 0），无 `any` 类型、无中文标识符。

## 边界条件（不做的事）
不包含：冲刺（Dash）的实现逻辑、无敌帧、冲刺冷却 UI（仅保留 action 占位接口）。
不包含：敌人、关卡系统、音效、美术资源、动画帧。
不包含：移动端虚拟摇杆/虚拟按钮（原型阶段优先桌面键盘）。
暂不支持：贴墙跳、土狼时间（coyote time）、跳跃缓冲（jump buffering）等进阶手感调优，后续需求再扩展。
超出范围：相机跟随、边界限制的具体调优参数不在本工单内实现。
